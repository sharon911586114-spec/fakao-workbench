# 法考刷题与学习工作台

一个**单文件、离线可用**的法考备考工作台（HTML），无需后端、无需联网即可刷题学习；也可接 GitHub 仓库实现多设备同步与数据云端存储。

## 功能
- 倒计时 / 八科进度总览
- 资料库（本地文本，直接打开查看）
- 刷题练习（内置题库，按章节/知识点细分）
- 错题本（导出）
- 考务信息
- 云端同步：手机 / iPad / 电脑共用同一份做题数据

## 使用
直接用浏览器打开 `index.html` 即可使用，所有数据保存在本机浏览器。

### 多设备同步（可选）
1. 开启本仓库的 GitHub Pages（Settings → Pages → main 分支）。
2. 在任意设备打开 Pages 链接。
3. 点右下角 ☁️ → 选 GitHub → 填：仓库（`owner/repo`）、分支（`main`）、Token（需 repo 权限）→ 启用。
4. 做题数据会自动提交到仓库的 `data/fk-data.json`，多端实时共享。
